# KV-Storage
Оптимизированное key-value хранилище на Python. Все данные хранятся в бинарном файле с поддержкой LRU Cache и Bloom Filter.

## Основные возможности
- `add` — добавить значение по ключу  
- `add_many` — вставить нескольких ключей из файла или итеративно
- `get` — получить значение по ключу  
- `delete` — удалить ключ  
- `keys` — получить список всех ключей  
- `clear` — очистить всё хранилище

## Реализация
- Все данные записываются в бинарный файл
- N записей хранится в LRU Cache заданного размера   
Формат `hash64(key): position`
- `Bloom Filter` обеспечивает ускорение проверки наличия ключа в файле

## Формат хранения
Каждая запись хранится в таком бинарном формате (в byte-порядке big-endian):

- `key_size` (4 байта, uint32) — размер ключа
- `key_bytes` — ключ (строка размера `key_size`)
- `value_size` (4 байта, uint32) — размер значения
- `value_bytes` — значение (произвольные байты размера `key_size`)

Схематично: `[key_size:4b][key_bytes][value_size:4b][value_bytes]`

## Оптимизация

**1. LRU Cache**

   Для более быстрого доступа к элементам реализован LRU-кэш, размер которого можно задать при создании хранилища.   
   Это значительно снижает количество обращений к файлу при частых запросах в силу быстрого доступа к часто используемым ключам по принципу Least Recently Used.  

   В кэше хранятся пары вида: `hash64(key): position`, где `hash64(key)` — 64-битный хэш ключа, а `position` — позиция записи в файле. Такой подход позволяет экономить оперативную память. 

**2. Bloom Filter**

Для быстрой проверки существования ключа в бинарном файле используется Bloom filter. Если ключ отсутствует в фильтре, значит, его *гарантированно* нет в файле (ложноположительные проверки возможны, ложноотрицательные — нет).

**3. Append-only модель**

Все записи добавляются в конец файла, что избавляет от неполных/поломанных записей и упрощает обновление данных.

## Необходимое для работы
1. Python 3.7+
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Использование через CLI

```bash
# Добавить пару ключ-значение
python main.py add key1 value1

# Добавить несколько пар из txt файла
python main.py add-many -f data.txt

# Добавить несколько пар интерактивно (формат: key,value)
python main.py add-many -i

# Получить значение по ключу
python main.py get key1

# Удалить пару по ключу
python main.py delete key1

# Показать все ключи
python main.py keys

# Очистить хранилище
python main.py clear

# Использовать другое хранилище
python main.py -s anotherstorage add key1 value1

# Использовать другую директорию для хранения
python main.py -d /path/to_storage add key1 value1
```
